# Nova AI

Nova AI is a desktop AI application built with Tauri, React, TypeScript, and Rust. It provides a fast desktop interface for interacting with AI-powered tools and workflows.

## Motivation

Nova AI was created to explore how modern AI capabilities can be integrated into a lightweight desktop application. The project focuses on combining a responsive React frontend with Tauri and Rust for a native desktop experience.

## Quick Start

### Prerequisites

Make sure you have Node.js, npm, Rust, and the Tauri prerequisites installed.

Clone the repository:

git clone https://github.com/rustoman-AI/Nova-AI.git

Move into the project directory:

cd Nova-AI

Install dependencies:

npm install

Run the application:

npm run tauri dev

## Usage

### Development

Start the application in development mode:

npm run tauri dev

The React and TypeScript frontend is located in the `src` directory.

The Tauri/Rust backend is located in the `src-tauri` directory.

### Build

Create a production build with:

npm run tauri build
